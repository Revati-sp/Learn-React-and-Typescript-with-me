# Learn React and TypeScript with me

Learning TypeScript and React step by step, from the basics. Each folder is one lesson and has its own README.

| Step | Folder | What I learned |
|---|---|---|
| 1 | [01-hello-world](01-hello-world/) | TypeScript basics: type annotations, compiling with `tsc` |
| 2 | [02-calculator](02-calculator/) | Calculator in plain TypeScript + DOM: union types, interfaces, narrowing, type guards |
| 3 | [03-calculator-react](03-calculator-react/) | Same calculator in React + TypeScript: components, props, `useState`, `useEffect` |

📖 **[Plain TypeScript vs React: what's the difference?](difference_02_and_03.md)** compares Step 2 and Step 3.

## Running a lesson
```bash
cd <folder>
npm install
```
Then follow the "How to run" section in that folder's README.
